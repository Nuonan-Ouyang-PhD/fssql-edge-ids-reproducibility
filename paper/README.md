# Manuscript status after the Pi4B implementation audit

The TeX and PDF files in this directory are the pre-audit revision associated
with the historical V4 evidence. They are retained for change tracking, but
they are **not submission-ready**.

The Pi4B policy, B1/B2 robustness, timing-decomposition and energy-comparison
claims must be removed or replaced after a corrected, preregistered execution.
Do not submit the current PDF as if those V4 results were valid. The Pi3B
results, Pi4B device calibration and saved one-shot official-test aggregate
have separate evidence boundaries and are not automatically invalidated by
the V4 worker findings.

No manuscript value should be changed to a favorable replacement until the
repair decisions are frozen and a technically valid corrected campaign is
completed. The official test must not be opened again.
